# PracticePython
### Repository: Beginner Python Projects Collection

A collection of small Python projects demonstrating core programming concepts such as user input handling, conditionals, loops, and basic algorithmic thinking.

---

### Projects Overview

* **Project_Bot-V1**
  A simple interactive chatbot that responds to user input using conditional logic.

* **Project_Expense-Splitter**
  Calculates and divides expenses among multiple users to determine individual shares.

* **Project_MadLibs**
  A word-based game that generates dynamic stories from user-provided inputs.

* **Project_Miles_to_Kilometers (vice versa)**
  Converts values between miles and kilometers with bidirectional functionality.

* **Project_Rock-Paper-Scissors**
  Implements the classic game against the computer with input validation and outcome logic.

* **Project_TaxCalculator**
  Computes taxes based on income, including basic income projection features.

* **Project_Temperature**
  Converts temperature values across different units such as Celsius and Fahrenheit.
